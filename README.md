# 🛍️ Khaneh-Zad | Modern E-Commerce Front-End
*(Scroll down for the Persian version / برای نسخه فارسی به پایین صفحه بروید)*

Welcome to my React-based e-commerce project! This is a fully responsive, modern storefront designed to provide a seamless shopping experience for handmade crafts and ceramics.

## 🌟 Live Demo
Experience the live project here: [Khaneh-Zad Online Store](https://b0rhandev.github.io/project-react/)

## ✨ Key Features
* **Interactive Shopping Cart:** Users can add/remove products and view the total price dynamically.
* **Dark/Light Mode:** Integrated theme switching for better user experience.
* **Responsive Design:** Flawless UI across mobile, tablet, and desktop screens.
* **Fast Loading:** Optimized build using Vite.

## 🛠️ Tech Stack
* **Core:** React.js, Vite
* **Styling:** Tailwind CSS
